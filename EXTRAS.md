# Adicionales reclamados

**En esta revisión no se reclaman puntos extra.** La entrega cubre solo la base: dos
escenarios (C1, C2), una métrica base por grupo y las vistas mínimas de eventos y alertas.

Ninguna de las funciones que ya existen se presenta como adicional: filtros simples de las
vistas, vistas de detalle de ventana o ejecución, `p50` y `cpu_percent` informativos, y la
regla `evidencia-insuficiente-v1`. Forman parte del tratamiento base de eventos, alertas y
datos insuficientes.
